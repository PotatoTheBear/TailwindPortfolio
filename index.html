HotCold

HotCold

The HotCold project was a school assignment that lasted 5 days. During this project I mainly focused on drawing 2-D art, but also wrote some code. This project consisted off four students including me. Day 1 was making a concept for a game that needed to use GPS tracking. Day 2 and 3 consisted of making a prototype that could be tested on day 4. During day 2 I drew a lot off backgrounds for in the app. During day 3 our coder got sick so I switched to coding. I coded a system that checked if you where further or closer from your objective. This was indicated with the backgrounds I drew.

Jestopia

Jestopia: Mike's Revenge

This is one of my Global Game Jam Groningen projects. It’s a simple puzzle game with "make me laugh" as a theme. I worked with a small team consisting out of 2 classmates, a friend from a different study and someone we met during the first day of the GGJG. During this Game jam I worked on most of the 2-D art assets for the game. Some of which you can see in the image above. You can find this project here: Jestopia: Mike's Revenge if you would like to take a look at the project we made.

Godot

Godot elective

During my studies I could also choose some electives. For one off my electives I chose to learn a bit about the Godot game engine. I made two small project using Godot. The first is a short story game where your choices make an impact on the story’s ending. I made this by using the dialogic plug-in. I also drew my own art for this using Clip studio. The other project was just trying out different thing in the engine. Like having a moving background using shaders and being able to change a sprite by clicking a button.

Racing

RaceGame

During this project I worked in a small team consisting of three students including myself. Who had to make a racing game within 5 days. We made this game in the unity game engine. The game has two game modes. One where you can try to beat your ghost and one where you drive multiple laps. During this project I mainly worked on the main/pause menus, the laps system and the big map where u can also play the game mode with the laps. This was the first 3-d project I worked on.

Portfolio website

This is also my first tailwind project which makes it a bit challenging, but also fun.
